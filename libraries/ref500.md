# Dataset handoff: `libraries/ref500`

**What it is.** 500 synthetic patient cards for adults presenting to Finnish primary care with chest or
general symptoms. Every card has a hidden truth (conditions and findings) and the pre-written result of
every test in the catalogue, for every state and attempt. Synthetic only; no real patient data.

| | |
|---|---|
| Library id (content hash) | `L_0dbfc37e2e45d8d4` (`python -m patient_engine library-info libraries/ref500` verifies it) |
| Catalogue | `catalogue/lung-primary-care`, locked as `catalogue-v1` (hash `2bcb9c78b2e0`); status draft, not clinically reviewed |
| Generator | the offline reference generator run through the model pipeline (`generate --fake`, seed 1): numbers drawn from the catalogue, **template text** (no language model). `provenance.generator` says `llm`, `model=fake` |
| Error rates | `guided`: which results are misses, false alarms or non-diagnostic is drawn from the catalogue's accuracy numbers |
| Audit | passes all 38 checks against the catalogue (`audit.md`, `audit.json` in the folder) |
| Files | `manifest.json`, `cards.jsonl.gz` (one `card/1` JSON per line), `audit.*` |
| Reproduce | `python -m patient_engine generate --catalogue catalogue/lung-primary-care --n 500 --seed 1 --out <dir> --fake` gives the same id |

## Mix (stratified, not prevalence-weighted)

83 lung cancer; 42 each of pneumonia, COPD exacerbation, asthma, heart failure, tuberculosis, benign nodule,
reflux or post-infectious cough; 41 each of no disease found, viral self-limiting, worried well. 27 cards
also have a co-existing ordinary illness. 362 cards have two states (`all_active` and
`<illness>_resolved`), 138 have one. To get a realistic population, draw a cohort (prevalence-weighted):
`python -m patient_engine cohort libraries/ref500 --n 20000 --seed 1`.

## A card (`card/1`, full spec in `patient_engine/card.py` and `catalogue/README.md`)

| Section | Visible to decisions? | Contents |
|---|---|---|
| `id` | no (the reveal handle gives an opaque id) | `lung_primary_care.s1:000007` |
| `background` | yes, from arrival | `age`, `sex`, `smoking_status`, `pack_years`, `region` |
| `presenting[state]` | yes, at first contact | `reported` (symptom ids) and `text` |
| `hidden.conditions` | **no: labels** | one `primary`, optionally one `coexisting`, with attributes (cancer: stage, location, histology) |
| `hidden.findings[state]` | **no: labels** | every variable below, with `value` and `caused_by` |
| `hidden.error_plan` | **no** | per test and attempt: correct / miss / false_alarm / wrong |
| `observations[state][test][attempt]` | only once that test and attempt is done | `status` (`ok`, `non_diagnostic`), `values` per output, `report` text |
| `notes` | only once the facts they `mention` are revealed | patient account, GP note |
| `provenance` | n/a | generator, model, prompts, catalogue hash |

**Hidden variables (42).**
Symptoms: cough, haemoptysis, dyspnoea, chest_pain, weight_loss, fatigue, appetite_loss, fever, hoarseness,
recurrent_chest_infection, wheeze. Signs: finger_clubbing, abnormal_chest_sounds, neck_nodes, ankle_oedema.
Lab truth: hb, platelets, crp, calcium, alp, ldh, cardiac_strain. Imaging truth: lung_lesion,
lesion_size_mm, lesion_location, mediastinal_nodes, distant_spread, consolidation, brain_metastasis.
Function: airflow_obstruction, fev1_pct_predicted. Tissue: lesion_malignant, histology_group. Definitive
markers `dx_<condition>` for each of the 10 conditions with one (none for no disease found and worried well).

**Tests (26)** with their outputs: history (the 11 symptoms), examination (the 4 signs), blood_count,
crp, crp_poc, chemistry, nt_probnp, chest_xray, chest_ct, low_dose_ct, pet_ct, brain_mri, spirometry,
bronchoscopy, ebus_tbna, ct_guided_biopsy, sputum_cytology, histology_report, and the definitive tests
dx_lung_cancer_histology, dx_pneumonia_chest_xray, spirometry_reversibility, echocardiography,
mycobacterial_culture, ct_nodule_followup, ph_monitoring, respiratory_virus_pcr. Group tests (chest X-ray,
CT, CRP, spirometry, NT-proBNP) say "one of a group" without naming the condition.

## How to use it

- **Read cards in Python:** `from patient_engine.library import load_library; lib = load_library("libraries/ref500"); lib.cards[0]`.
- **Simulate decisions:** never give a whole card to a decider. Use `patient_engine.reveal.RevealHandle(card, catalogue=cat)` or run the encounter loop on it; deciders see only `patient_engine.record.Record`.
- **Train the JEV:** use the training export (`python -m pathway_sim export-training ... --library libraries/ref500`, WP-W4-4) so inputs are records as they stood at each decision and labels are kept outside the input.
- **Caveats:** template wording (a model can learn the template; test on a model-written library too); 177 of about 260 catalogue numbers are assumptions; the mix is stratified, not realistic, until drawn as a cohort.
