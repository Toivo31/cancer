## Presenter notes
"Every patient here has a sealed truth: what they really have and what every test would show, drawn before day one.
The system only sees the record on the right." Click **Lift the seal**: "This one was lung cancer; the antibiotics on
day forty-five treated something she did not have. The optimiser never sees this side. It reads records, proposes a
reordering, reruns the same patients, keeps it only if faster with no more missed cancers, then we report the result
on new patients: in Norway forty to sixty-seven percent at best fit." Point at the caption: "Rerunning the same
patients only works in a simulator; in a hospital that is a pilot."

## Open issues and judgement calls
- **Selection optimism number left out.** `selection_optimism_pp` is only in `demo_bundle.json` (not readable from
  file://). The page explains it in words and links index.html, which shows it. QUESTION posted to main.
- **`encounter.html?p=` is not read by encounter.js** (QUESTION to L6). Until it is, "Watch this patient visit by
  visit" opens the loop (with truth if lifted) but not on that patient.
- Step five uses the Norway no-equipment result (D68 headline) with the claim id `sim-no-noequipment-vs-scanner`, as
  L4 does; the register has no claim id for the 40→67 number itself.
- The "sealed truth" in the bundle has conditions, cancer flag, caption and treatment marks, not every test's pre-drawn
  result; the redacted bars (Condition, Chest X-ray, CT scan, Biopsy) are illustrative labels, not data.
- The example card under DETAILS comes from `gemini_s2_30` (results prompt g2@1, the leaking one); its test reports
  are not shown, and its history line contradicts its complaint ("no cough" vs "coughing constantly"). Copied as-is from
  the Overview; worth a look by Tuomas.
- "Why this is not overfitting" is the first finding below DETAILS instead of a paragraph above it (keeps the top
  near the 80-word budget); the loop's steps four and five carry the point above the rule.
- Skim check: read only the part above DETAILS in the 1440×900 shot; message in one sentence: "patients have a hidden
  truth, the optimiser only learns from records and the number is measured on new patients". Nobody else has read the text yet.
