## Open issues and judgement calls (for Tuomas)
- **Infographic form:** one proportional bar plus three count blocks (big number, basis chip, one-line meaning) in a
  card, beside the worked example (two stacked bars: published / tuned to a published figure / assumption). The
  framing sentence sits below both, verbatim, as a quote. The top is longer than about eighty words because the brief
  puts the framing sentence there.
- **Chip colours:** published = solid ink; simulation = mustard tint, solid mustard border; assumption = brick tint,
  **dashed** brick border. Works in greyscale (solid black / light solid / dashed). Brick slightly bends the theme rule
  ("brick means wrong"); the dashed tint is meant as "caution, our choice". An alternative is ink-outline only.
- **Rows start collapsed** (48 rows; a deep-linked row opens). Open all / Close all buttons, and a filter by basis
  (the three count blocks also set the filter).
- **Order below DETAILS:** What we could not support (first, never folded) → claims by theme → waiting split tables →
  sources (cited-by-a-claim first, then the rest).
- Worked-example labels say "Finnish pathway · synthetic county" and "Norwegian hospital · Stokstad et al.";
  "set from or tuned to a published figure" is the bundle's `fi_matched_pct` (published + calibrated).
- Abstract-only and secondary access are shown in brick text, as a caution mark.
- **Links in:** Evidence (L4, merged) already links `research.html` and `research.html#<id>`; Overview (L2) adds
  claim links per its FYI. Still open: `index.html` screens 2 and 4 (L6, bundle block frozen) and the simulator, if
  wanted (ids are in each claim's `shown_on`).
