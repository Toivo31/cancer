# Evidence ledger

Generated by `python3 params/ledger.py` from `params/sources.yaml`, `scenarios/*.yaml` and `params/*.yaml`. Nothing here is counted by hand; rerun the script after any change to those files (`--check` fails when this file is stale). Machine-readable copy: `docs/ledger.json`.

## What is counted

- **Block**: a mapping with a `source:` key (a test, a resource, a condition, a group, a decision mix, the arrival stream) in a scenario file. One block is one row of the ledger. The same decision mix repeated in several flowcharts is one row.
- **Input vs target**: blocks under `finnish_targets` and `published` are calibration targets or published comparators the engine does not read as inputs; they are reported separately.
- **Grade** of a sourced block is how we read the cited source (`access` in `params/sources.yaml`): `full_text`, `abstract`, or `secondary` (news, unpublished, or seen only through another document). Study design and setting are not recorded there, so no A/B quality grade is computed.
- **Mixed**: a sourced block whose own note says part of it is an assumption, a calibration or a placeholder (for example the GP clinic is sourced for its booking lead, while its capacity is an assumption). The *strict* sourced count leaves these out.
- **Numbers** are the numeric values inside the blocks (probabilities, days, capacities, shares); this is a finer count than blocks.
