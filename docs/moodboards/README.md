# Moodboards

Visual and tonal references for the Junction 2026 video, pitch and demo. Each board has its own folder.

| Folder | What it is | Live version |
|---|---|---|
| [`video-mood-board/`](video-mood-board/README.md) | The trailer's mood: boards 01 to 04 (waiting rooms, paper and machines, queues in print, direction) built from 15 AI-generated images | https://claude.ai/artifact/K2kTsmKrjiBPs93PPRN3Mk |
| [`demo-ui-moodboard/`](demo-ui-moodboard/README.md) | The look of the working demo page (`demo/index.html`): palette, type, texture, six real screens | https://claude.ai/artifact/9aW6uHLcy8C2h3rcUckTQ2 |
| [`simulation-moodboard/`](simulation-moodboard/README.md) | The look of the dots animation (`video/dots/` on `main`): black stage, one dot per patient, seven frames | the PNG is in the folder |

**The video and demo boards describe two looks on purpose.** The video board is the film world (teal-black, cream paper, grain). The demo board is the product screen (night blue, mono numerals, four meaning colours). The trailer script says when it moves from one to the other: from the product beats on, match the demo board. The simulation board covers the dots animation, which uses the same black-stage idea with its own colours.

**About the images.** The 15 images of the video board were uploaded to the live artifact from another chat and can't be downloaded from there. This folder holds the written boards (captions, notes, palette, direction) and the file names the images should have; drop the originals into `video-mood-board/images/` using those names. The demo board's six screenshots are included.
