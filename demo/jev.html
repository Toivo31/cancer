JEV, the team's decision model

A decision model, not a chatbot. It reads a context, takes a question with a fixed list of allowed answers, and returns one score per answer in a single pass. The answers are what the pathway allows at that node, so it can only propose a step that exists.

Optional, off by default: the backbone's original language head calls read-only tools and writes a short evidence summaryappended to the context
Contextrecord, symptoms, notes, tool results→ Frozen backbone + trained adapters→ context vector
Each answer, with its questionencoded on its own→ same encoder→ one vector per answer
Scoring head: the answers attend to each otherscore = direct match with the context + a correction from the whole answer set→ one score per answersoftmax over the offered answers→ a person accepts or overrides
