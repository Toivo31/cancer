    How a change is found
    1. Run today's pathway on training patients, truth sealed.
    2. Read the records: which step held patients back, which tests did not help.
    3. repeatPropose one change to the order of steps.
    4. Rerun the same patients. Keep the change only if faster and no more cancers missed.
    5. Test on new patients, truth sealed again. This is the number we report. Our simulation

    Details

    The reported number comes from patients the search never saw

    The optimiser proposes changes from revealed information only: the records, never the sealed truth. A change is kept only if a rerun of the same training patients is faster without missing more cancers. The number we report is then measured on new patients, drawn separately, whose truth stays sealed during the search. A search that tries many changes and keeps the best can look better on its own training patients than it will on new ones. That gap is called selection optimism; reporting only new patients keeps it out of the number, and the full results report shows how large it was for each result.

    Rerunning the same patients is a simulator privilege; in a hospital it is a pilot

    Because every result of every test is drawn before the first visit, the simulator can send the very same patients down a changed pathway and compare like with like. A real hospital cannot rerun a patient. There, the fourth step becomes a pilot on new patients, with the noise that brings. The simulator tells you which change is worth piloting; it does not replace the pilot.

    Judging a test in hindsight flatters the tests that come late

    Reading the records invites the question: should the test that finally found the cancer have come first? Answered patient by patient, this misleads. That test was only run on patients whose earlier tests had failed, those earlier tests may be what kept its queue short, and it may be slow, scarce or invasive. So the optimiser reads groups of patients rather than single stories, counts a step that settles patients without cancer as useful, and proves a change only by rerunning the whole pathway.

    The same hidden facts, written two ways

    Every patient starts as a hidden set of facts: what is truly wrong, and what each test would show. A language model, or a plain template, turns those facts into the words a clinician would meet. The decision model only ever sees the words. It never sees the hidden facts.

    The medical content is a draft no clinician has read

    Conditions, hidden findings and tests, with each test's accuracy, turnaround and cost, live in a care catalogue. Patients are drawn from it, so the simulator is right about this catalogue's world, not about medicine.

    Our assumption

    The first model-written test reports gave the answer away, so their wording is not used

    In the first model-written libraries the wording of a test report revealed which results were misses or false alarms. Values, complaints and histories were fine, but the report text could not be used to train or test a model that reads text. Later libraries write report text from the values alone, with the model never seeing the true condition. Each library records which version of the results prompt wrote it.

    Each library is checked before use

    An audit compares a library against the catalogue: how often each finding and each test result appears per condition, against the frequencies the catalogue expects, plus a check that notes do not name the hidden condition. Small libraries skip some checks for too few cases. Audit results sit with each library.

    What these patients cannot tell you

    • They teach the catalogue, not medicine: most of its numbers are our assumptions.
    • Who gets which test, and when, comes from placeholder decision tables and random exploration, not from doctors.
    • Every library holds about the same number of cards per condition; the realistic mix is applied when patients are drawn, so rare conditions repeat the same few cards.
    • Findings are independent given the condition, repeated tests are independent given the patient, and disease does not progress while a patient waits.
    • One main condition per patient, at most one other illness, and only people who present with chest symptoms.
    • Template wording repeats; a model can learn the phrasing instead of the patient.
